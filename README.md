# OTOSHI Launcher Policy Site

Static landing page and privacy policy for OTOSHI Launcher.

## Files
- `index.html` - Application website landing page.
- `privacy.html` - Privacy policy.
- `CNAME` - Custom domain for GitHub Pages.

## Domain setup
Update `CNAME` with the domain you want to use:
- `otoshi-launcher.me` (root domain), or
- `policy.otoshi-launcher.me` (policy subdomain).

After updating, set the same domain in GitHub Pages settings and in Epic brand
settings for the Application Website and Privacy Policy URL fields.
